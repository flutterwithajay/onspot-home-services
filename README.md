# 🏠 OnSpot - Home Services App

A Flutter-based on-demand home services app that connects customers with professional service providers for various home needs. From plumbing and electrical work to cleaning and repairs, OnSpot makes hiring trusted professionals quick and easy.

## 🚀 How It Works

1. Customer browses available services or searches for specific needs
2. Books a service with preferred date and time
3. Gets matched with nearby verified professionals
4. Professional arrives at scheduled time
5. Service completed and payment processed
6. Rate and review the service

## ✨ Features

### For Customers
- 🔍 Browse & search services (Plumbing, Electrical, Cleaning, AC Repair, etc.)
- 📅 Book appointments with preferred date/time
- 📍 Real-time professional tracking
- 💳 Multiple payment options (Cash/Card/UPI)
- ⭐ Rate and review completed services
- 📱 Service history and past bookings
- 🔔 Real-time booking notifications

### For Service Professionals
- ✅ Manage service requests
- 📊 View daily/weekly schedule
- 📍 Navigation to customer location
- 💰 Track earnings
- 📈 Service completion history

### General Features
- 🔐 Secure phone/email authentication
- 📍 Location-based service matching
- 💬 In-app chat between customer and professional
- 🎯 Real-time booking updates
- 📸 Before/after service photos

## 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| Flutter | Cross-platform mobile framework |
| Dart | Programming language |
| Firebase Authentication | User login & security |
| Firebase Firestore | Real-time database |
| Firebase Cloud Messaging | Push notifications |
| Google Maps API | Location & tracking |
