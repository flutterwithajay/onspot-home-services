# OnSpot Home Services

OnSpot Home Services is a Flutter-based home service application that connects **customers with service providers**. Service providers can add and manage their services, while customers can browse available services and purchase the services they need.

## 🚀 Features

* 🔐 User authentication
* 👤 Customer and service provider functionality
* 🏠 Browse home services
* ➕ Service providers can add services
* 🛒 Customers can purchase services
* 🔥 Firebase integration
* 📱 Simple and user-friendly Flutter interface

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Firebase**
* **Firebase Authentication**
* **Firebase Firestore / Realtime Database**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/flutterwithajay/onspot-home-services.git
```

### 2. Navigate to the project

```bash
cd onspot-home-services
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Configure Firebase

Connect the application to your Firebase project and add the required Firebase configuration files for your target platform.

### 5. Run the application

```bash
flutter run
```

## 🎯 Project Purpose

The purpose of OnSpot Home Services is to provide a convenient platform where customers can discover and purchase home services while service providers can offer their services through the application.
